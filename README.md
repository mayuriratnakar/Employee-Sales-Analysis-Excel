# Employee-Sales-Analysis-Excel
Employee Sales Analysis Dashboard using Microsoft Excel, featuring Pivot Tables, Charts, Slicers, Logical Functions, and Lookup Functions.

Employee Sales Analysis Dashboard – Microsoft Excel

Project Overview

This project focuses on Employee Sales Analysis and Dashboard Creation using Microsoft Excel. It demonstrates practical Excel skills, including Pivot Tables, Pivot Charts, Interactive Slicers, Logical Functions, Lookup Functions, and Conditional Aggregation Functions.

The project analyzes employee sales performance, tracks target achievement, and presents key business insights through an interactive dashboard.

Project Features

1. Pivot Table Analysis

- Created Pivot Tables to summarize employee sales data.
- Analyzed total sales by department.
- Compared sales targets with actual sales.
- Organized and summarized employee performance data.

2. Interactive Employee Sales Dashboard

Created an interactive dashboard containing:

- Total Sales: Overall sales generated by employees.
- Total Employees: Number of employees included in the dataset.
- Average Sales: Average sales per employee.
- Target Achievement: Percentage of sales target achieved.
- Pivot Table analysis.
- Pie Chart for sales distribution.
- Column Chart for sales comparison.
- Interactive Slicers for filtering and analyzing data.

3. Logical and Conditional Functions

Practiced various Excel functions using employee sales data:

- IF
- Nested IF
- AND
- OR
- NOT
- IFERROR
- SUMIF
- SUMIFS
- COUNTIF
- COUNTIFS
- AVERAGEIF
- AVERAGEIFS

4. Lookup Functions

Implemented lookup functions to retrieve employee-related information:

- VLOOKUP
- HLOOKUP
